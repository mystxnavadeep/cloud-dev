# rclone filter rules for DeepSeek Harness workspace backup

# Exclude node_modules and package caches
- **/node_modules/**
- **/.npm/**
- **/.yarn/cache/**
- **/.pnpm-store/**
- **/.bun/**

# Exclude build and framework caches
- **/.next/cache/**
- **/.turbo/**
- **/.cache/**
- **/.parcel-cache/**
- **/dist/**
- **/build/**
- **/.output/**

# Exclude Python bytecode and virtualenv caches
- **/__pycache__/**
- **/*.pyc
- **/*.pyo
- **/.pytest_cache/**
- **/.mypy_cache/**
- **/.ruff_cache/**
- **/.venv/**
- **/venv/**

# Exclude temporary, lock, and OS files
- **/*.tmp
- **/*.temp
- **/*.swp
- **/*.swo
- **/*~
- **/.DS_Store
- **/Thumbs.db
- **/*.pid
- **/*.sock

# Exclude runtime sockets and logs
- **/.dsh/logs/**
- **/.dsh/cache/**
- **/tmp/**

# Exclude sensitive credentials and private keys
- **/.git-credentials
- **/.rclone.conf
- **/*id_rsa*
- **/*id_ed25519*
- **/*.pem
- **/*.key
- **/.env.local
- **/.env.*.local
- **/.vercel/auth.json
- **/.wrangler/config/default.toml

# Include everything else (source files, configs, documentation, git metadata)
+ **
