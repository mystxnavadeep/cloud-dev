# rclone filter rules for DeepSeek Harness workspace backup

# Exclude package manager node_modules and dependency caches
- **/node_modules/**
- **/.npm/**
- **/.yarn/cache/**
- **/.pnpm-store/**
- **/.bun/**

# Exclude build tool caches (preserving actual build outputs)
- **/.next/cache/**
- **/.turbo/**
- **/.cache/**
- **/.parcel-cache/**

# Exclude Python bytecode and virtualenv caches
- **/__pycache__/**
- **/*.pyc
- **/*.pyo
- **/.pytest_cache/**
- **/.mypy_cache/**
- **/.ruff_cache/**
- **/.venv/**
- **/venv/**

# Exclude temporary, editor, and OS files
- **/*.tmp
- **/*.temp
- **/*.swp
- **/*.swo
- **/*~
- **/.DS_Store
- **/Thumbs.db
- **/*.pid
- **/*.sock

# Exclude runtime temporary files and logs
- **/.dsh/logs/**
- **/.dsh/cache/**
- **/tmp/**

# Exclude sensitive credentials and private keys
- **/.git-credentials
- **/.rclone.conf
- **/*id_rsa*
- **/*id_ed25519*
- **/*.pem
- **/*.key
- **/.env.local
- **/.env.*.local
- **/.vercel/auth.json
- **/.wrangler/config/default.toml

# Include all source code, project files, artifacts, and documentation
